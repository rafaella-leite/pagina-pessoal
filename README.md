# 💻 Portfólio Pessoal

Portfólio pessoal desenvolvido como atividade prática do curso de **Sistemas de Informação da Universidade Federal de Lavras (UFLA)**.

O projeto apresenta minha trajetória profissional e acadêmica, habilidades, interesses e alguns projetos desenvolvidos.

Um dos objetivos da atividade foi explorar o desenvolvimento de interfaces utilizando diferentes frameworks CSS. Por isso, o portfólio foi desenvolvido em **duas versões: Bootstrap e Bulma**.

## 👩‍💻 Sobre mim

Sou **Rafaella Leite**, designer com mais de 5 anos de experiência na área criativa e graduanda em Sistemas de Informação.

Tenho interesse na união entre **design e tecnologia**, principalmente nas áreas de desenvolvimento web, UI/UX, interfaces digitais e comunicação visual.

## 🎨 Frameworks utilizados

### Bootstrap

A primeira versão do portfólio foi desenvolvida utilizando **Bootstrap**, explorando recursos como:

- Sistema de Grid
- Navbar
- Cards
- Buttons
- Badges
- Progress Bars
- Classes utilitárias
- Responsividade

### Bulma

A segunda versão foi desenvolvida utilizando **Bulma**, mantendo a proposta visual e o conteúdo da página, mas adaptando sua estrutura para os componentes e classes oferecidos pelo framework.

Foram utilizados recursos como:

- Columns
- Navbar
- Cards
- Buttons
- Tags
- Progress
- Classes responsivas
- Helpers

Essa implementação permitiu comparar diferentes formas de construir uma mesma interface utilizando frameworks CSS distintos.

## 📱 Responsividade

As duas versões foram desenvolvidas para se adaptar a diferentes tamanhos de tela, incluindo computadores, tablets e dispositivos móveis.

## 🌙 Tema claro e escuro

O projeto possui alternância entre tema claro e escuro utilizando **JavaScript**, com armazenamento da preferência do usuário através do `localStorage`.

## 🎯 Objetivo

O objetivo do projeto é aplicar conceitos de desenvolvimento web na prática, explorando HTML, CSS, JavaScript, responsividade e frameworks CSS.

A criação das versões em **Bootstrap e Bulma** também permite observar as diferenças de estrutura, classes e componentes entre os dois frameworks.
